# Use a Wi-Fi or other printer

## Wi-Fi (LAN) receipt printer

Best when **several phones share one printer** — each phone prints over the shop's Wi-Fi.

1. Connect the printer to your shop's **Wi-Fi router** (see the printer's manual).
2. Find its **IP address** — most printers print it on the self-test page (hold **FEED** while
   switching on). Ask whoever set up your router to **reserve** that IP so it never changes.
3. In Galla Peti: **Settings → Printer & paper → Wi-Fi**. Enter the **Printer IP address** (for
   example `192.168.1.50`) and **Port** `9100`.
4. Tap **Test print**, then **Save**.

The phone must be on the **same Wi-Fi** as the printer (not mobile data). Do the same on each phone.

## Any other printer (A4, inkjet, PDF)

Choose **Settings → Printer & paper → Other**. When you tap **Print**, Android's print screen opens —
pick any printer your phone can reach, or **Save as PDF**.

In this mode bills are **not** printed automatically; tap **Print** when you need one.
