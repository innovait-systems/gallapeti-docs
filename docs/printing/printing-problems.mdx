# Printing problems

| Problem | Fix |
|---|---|
| Printer not in the list | Switch it on and keep it close, then tap **Scan for printers**. |
| "Turn on Bluetooth" | Switch on Bluetooth from your phone's quick settings. |
| "Could not connect to printer" | Turn the printer off and on, move closer, and try again. If another phone is connected to it, disconnect that phone. |
| Only half the bill prints, or lines are missing | Turn on **Slow printer mode** in **Settings → Printer & paper → Options**. |
| Text wraps oddly or is cut off | Choose **Custom** paper and adjust **Characters / line** — see [Paper size](paper-size.mdx). |
| Paper comes out blank | The paper roll is upside down — the shiny side must face the print head. |
| Wi-Fi printer not reachable | Check the phone is on the same Wi-Fi and the printer's IP address hasn't changed. |
| Logo prints dark or blurry | Use a simple, high-contrast logo. Thermal printers print black only. |
