# Install Galla Peti

**When you'd use this:** the first time you start using Galla Peti, or on a new phone.

## Steps

1. **Open Google Play** on your Android phone and search for **Galla Peti**, or open the link
   from the [Galla Peti website](https://gallapeti.innovait-systems.com).
2. Tap **Install**. The app is free.
3. Open **Galla Peti** from your home screen.

:::info[Early testers]
If you received Galla Peti as an APK file before it was on Google Play, first create a backup in the
old app (**Settings → Backup & restore → Create backup**). Then install from Google Play, tap
**Restore from backup** on the welcome screen, and uninstall the old app.
:::

## What you need

- An Android phone (Android 7 or newer).
- No internet — Galla Peti works offline. Internet is only used when you share a bill on WhatsApp
  or email.
- Optional: a Bluetooth or Wi-Fi receipt printer — see [Connect a Bluetooth printer](../printing/connect-bluetooth-printer.mdx).
