# Shop details, logo and UPI IDs

Open **Settings → Shop details**. Changes apply to new bills.

## Shop

- **Logo** — tap the image to change it; **Remove logo** to take it off bills. Simple, dark logos
  print best on thermal paper.
- **Shop name**, **mobile number** and **address** — printed at the top of bills.

## Tax & payments

- **GSTIN** — Galla Peti checks it for typos and fills in your state. Leave empty if you're not
  GST registered; then bills don't add GST.
- **UPI IDs** — your first UPI ID is the **primary** one, printed on bills. Tap **Add another UPI ID**
  to add backups (up to 4). At checkout you can swipe to the next QR if a payment fails.
  **Make primary** moves a backup to the top. Galla Peti shows each ID's app (Google Pay, PhonePe,
  Paytm…).

## Billing

- **Prices include GST** — the default for new items.
- **Round off to nearest rupee** — rounds bill totals.
- **Bill number prefix** — bills look like `A1/26-27/0001`. Use a **different prefix on each phone**
  so numbers never clash — see [Use several phones](multiple-phones.mdx).
- **Bill footer** — the thank-you line at the bottom of bills.

Tap **Save**.
