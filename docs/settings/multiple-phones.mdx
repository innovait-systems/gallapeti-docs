# Use several phones

You can install Galla Peti on several phones in one shop — for example two counters during the
Diwali rush. Each phone keeps **its own** items, bills and reports.

## Set it up

1. **Give each phone a different bill number prefix** — **Settings → Shop details → Bill number
   prefix**: `A1` on the first phone, `A2` on the second… Bill numbers then never repeat, as GST
   requires.
2. **Copy your items** — on the first phone: **Items → Import / Export Excel → Export my items**.
   Send the file to the other phone and **Import** it there.
3. **Share a printer** — use a [Wi-Fi printer](../printing/wifi-printer.mdx); most Bluetooth printers
   only connect to one phone at a time.

:::caution[Restoring a backup on another phone]
A restored backup carries the first phone's prefix. **Change the prefix** on the new phone straight
away.
:::
